# Video Games Sales Dashboard (Power BI)
An interactive Power BI dashboard analyzing global video game sales from 1980–2020, built from a public Kaggle dataset.

## What it shows
- Total global sales and total games in the dataset (KPI cards)
- Global sales by genre (bar chart)
- Sales trend over time, showing the industry peak around 2008–2009 (line chart)
- Regional sales breakdown by platform — North America, Europe, and Japan (stacked bar chart)
- Interactive filters by year and genre (slicers)

## Tools
Power BI Desktop, Power Query for data cleaning


## Dataset
[ Worldwide Video Game Sales dataset, Kaggle] (https://www.kaggle.com/datasets/rishidamarla/worldwide-video-game-sales)
